Draw sound on the web.

SonicFrame draws a sound on a canvas, follows it while it plays, and lets people seek with a click, a drag or the keyboard. No dependencies, any framework, a strict Content-Security-Policy.

Install

One package, nothing else to install. Use the player from JavaScript, or write it as a tag. 

npm install sonicframe

In JavaScript

import { createPlayer } from 'sonicframe/player';

createPlayer({
    container: document.querySelector('#voice'),
    src: '/voice.mp3',
    theme: 'bubble',
});

As an HTML tag

<sonic-player src="/voice.mp3" theme="bubble">
</sonic-player>

<script type="module">
    import { defineSonicPlayer } from 'sonicframe/player';
    defineSonicPlayer();
</script>

This player is the tag above, on this page.
