Draw sound on the web.

SonicFrame draws a sound on a canvas, follows it while it plays, and lets people seek with a click, a drag or the keyboard. No dependencies, any framework, a strict Content-Security-Policy.

Install

One package, nothing else to install. Use the player from JavaScript, or write it as a tag. 

npm install sonicframe

In JavaScript

import { createPlayer } from 'sonicframe/player';

createPlayer({
    container: document.querySelector('#voice'),
    src: '/voice.mp3',
    theme: 'bubble',
});

As an HTML tag

<sonic-player src="/voice.mp3" theme="bubble">
</sonic-player>

<script type="module">
    import { defineSonicPlayer } from 'sonicframe/player';
    defineSonicPlayer();
</script>

This player is the tag above, on this page.

The wave in words

For people who cannot see the wave: a short description of the sound, read by their own screen reader when they reach the player. It is shown here as text too. Off until you turn it on.

With the wave focused, D says the description again and P or Shift+P steps between the parts. The speech bubble reads it with your browser’s own voice. 

createPlayer({
    container,
    src: '/voice.mp3',
    lang: 'pt',
    description: {
        keys: true,
        pauseInValue: true,
        button: true,
        pulse: true,
    },
});
