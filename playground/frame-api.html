Frame methods and events

Everything a frame does after it is made, plus the two controls that come with it: the play button and the volume control.

Methods

Method What it does
SonicFrame.create(options) Same as new SonicFrame(options).
setPeaks(source) New peaks: a list, { peaks, duration }, a loader or null.
bind(media) Follow another media element, or none.
setDuration(seconds) The length to use until the media knows its own.
setProgress(ratio) The position shown while no media is bound.
seekTo(ratio) Move there (the media too) and emit seek.
setView(start, end) Show part of the sound; zoom on only.
zoomTo(level, at?) Zoom to a level around a ratio (or the anchor).
zoomBy(factor, at?) Zoom in (above 1) or out (below 1).
scrollTo(start) Move the view to begin at a ratio, keeping its size.
setBar(bar), setWave(wave), setColors(colors) Change part of the look.
setLabel(label) Change the accessible name.
refresh() Read the colors again after your own theme switch.
exportClip(options) Record a video of a stretch; see clips.
use(plugin) Add a plugin; returns the function that removes it.
on(event, listener) Listen; returns the function that stops.
destroy() Remove everything SonicFrame added. Safe to call twice.

Properties

progress (0 to 1), duration (seconds or null), peaksDuration, peaks, container and view ({ start, end, level, maxLevel }, the whole sound while zoom is off), all read-only.

Events

Event Arguments When
seek { ratio, time, source } A click, drag, key or seekTo; source is 'pointer', 'keyboard' or 'api'.
hover ratio, time The mouse moved over the wave (null when it left).
timeupdate time, ratio The media moved, at its own pace.
durationchange duration The length became known or changed.
peakschange peaks The peaks arrived, were replaced or went.
resize geometry The wave changed size, or got its pixels.
rangeend A played range ended or was abandoned.
viewchange view, source The view moved: 'api', 'wheel', 'keys', 'pinch', 'follow', 'edge', 'minimap' or 'button'.
error error Loading peaks or a plugin's work failed.
destroy The frame was destroyed.

The play button

import { PlayButton } from 'sonicframe';

PlayButton.create({ container, media, shape: 'circle', fill: 'solid', size: 32 });
Option Default What it does
container (required) Where the button goes.
media null What it plays and pauses (disabled without one).
shape 'circle' 'circle', 'rounded' or 'square'.
fill 'solid' 'solid', 'outline' or 'ghost'.
size 32 CSS pixels.
radius null Corner radius instead of the shape's own.
colors the theme's { background, icon }.
labels Play / Pause The accessible names.
exclusive true Starting this media pauses every other exclusive one.

setLook, bind, on('error', …) (the browser refused to play) and destroy.

The volume control

import { VolumeControl } from 'sonicframe';

VolumeControl.create({ container, media, slider: 'hover' });
Option Default What it does
container, media Where it goes, and what it controls.
slider 'always' 'always' or 'hover' (opens on hover or focus).
size 32 The speaker button, CSS pixels.
width 80 The bar's width, CSS pixels.
step 0.05 How far an arrow key moves the level.
colors the theme's { icon, track, fill }.
labels English { mute, unmute, volume }.

It follows the media's own volume and muted, so other controls stay in step. Where a page cannot set the volume (iOS), only the mute button shows.
