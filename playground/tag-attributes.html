Tag attributes

Every attribute of <sonic-player>. Words inside an attribute turn its extras on; anything unknown is ignored.

Attributes

Attribute Values Player option
src an address src
preload none, metadata, auto preload
peaks a .dat, audiowaveform JSON or list address peaks: () => loadWaveform(…)
peaks-channel all or a number channel
peaks-max a number maxPeaks
peaks-normalize present normalize: true
theme a theme's name theme
palette a palette's name, auto palette
wave a drawing's name wave
font a stack name or family font
font-src, font-stylesheet an address font: { src }, font: { stylesheet }
label text label
volume present volume: true
spectrogram present spectrogram: true
zoom wheel scroll pinch keys follow center edges buttons zoom
zoom-max a number zoom.max
minimap present; above autohide wheel minimap
chapters a WebVTT or Podcasting 2.0 JSON address chapters: { src }
chapter-options list open lane above announce images links no-keys no-lines chapters
a11y-lang a language tag, auto a11y.lang
a11y-description present; keys pauses speech announce button animation fade a11y.description
a11y-zoom announce a11y.zoom.announce
a11y-minimap keys a11y.minimap.keys

Changing an attribute updates the player; the ones that change what is built (the sound, its peaks, zoom, the minimap, the chapters, the words) build it again.
