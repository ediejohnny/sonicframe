Markers

Flags on moments of the sound: chapters, comments, the places a teacher wants a student to hear. A click jumps to one, and M steps through them.

Adding markers

import { markers } from 'sonicframe';

const flags = markers({
    marks: [
        { time: 2.4, label: 'Title' },
        { time: 9, label: 'Second line' },
        { time: 21, label: 'Last lines', color: 'var(--danger)' },
    ],
});
frame.use(flags);

flags.set([3, 18]); // replace them; plain times work too

Times are in seconds, so markers stay in place when the wave changes size; nothing is drawn while the length is unknown. Markers that crowd together become one pill with a count.

Options

Option What it does
times Moments in seconds (the simple form).
marks { time, label, color, id } (the richer form).
color Any CSS color or var(--name) for a plain marker.
width Line width in CSS pixels.
group Markers closer than this many pixels become one pill.
snap A click on a marker seeks to its exact moment.
tooltip Show a tooltip on hover.
backGrace Seconds after a marker within which Shift + M goes to the one before (1; 0 lands on it).

Keys

With the wave focused, M goes to the next marker and Shift + M to the previous, like a player's tracks. Zoomed in, a marker reached by a key comes into view. Caps Lock changes nothing.
