A chat voice note

A message bubble with a voice note: a round play button, a slim wave, the length under it, a speed button, and the long pauses skipped. A chat can hold hundreds of them.

The bubble

import { createPlayer } from 'sonicframe/player';

createPlayer({
    container: bubble,
    src: note.url,
    preload: 'none',
    peaks: note.peaks, // saved with the message when it was recorded
    theme: 'bubble',
    label: `Voice note from ${note.author}, ${note.length}`,
});

The bubble theme already puts the time and the speed under the wave, like a messenger. On a phone, any player turns into this arrangement on its own; see the voice note on phones.

Peaks when the note is recorded

The recorder already has the samples: compute 60 or so peaks and send them with the message, so the bubble draws at once and the audio loads only on play. 

import { peaksFromChannel, silencesFromPeaks } from 'sonicframe';

const peaks = peaksFromChannel(recording.getChannelData(0), 60);
const silences = silencesFromPeaks(peaks, recording.duration, { minDuration: 1.5 });

Skip the long pauses

import { skipSilences } from 'sonicframe';

createPlayer({
    container: bubble,
    src: note.url,
    peaks: note.peaks,
    theme: 'bubble',
    plugins: [skipSilences({ silences: note.silences, dim: true })],
});

Hundreds in one chat

  • Each player keeps its pixels only near the screen and loads its peaks there.
  • Every frame shares one resize observer, one visibility observer and one animation loop.
  • Play buttons are exclusive: starting one note pauses the one playing.
  • With preload: 'none', nothing is downloaded until a note is played.
