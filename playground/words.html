The wave in words

For people who cannot see the wave: a short description of the sound, read by their own screen reader when they reach the player. It is shown here as text too. Off until you turn it on.

Loading the sound…

Try it

Keys

  • D says the description again
  • P and Shift + P step between the parts
  • The speech bubble reads it with your browser’s own voice

In code

createPlayer({
    container,
    src: '/voice.mp3',
    a11y: {
        lang: 'pt',
        description: {
            keys: true,
            pauseInValue: true,
            button: { animation: true, animationType: 'pulse' },
        },
    },
});

On a frame of your own, it is the soundDescription plugin: 

import { soundDescription } from 'sonicframe';

frame.use(soundDescription({ lang: 'pt', keys: true }));

What it says

How long the sound is, where the sound and the pauses are, and where it is loudest: "33 seconds. Sound until 20 seconds, a pause of 4 seconds, then sound to the end. Loudest at 12 seconds." A sound with many pauses is summed up by its longest one, and the silence at the start and the end is told apart.

It says "sound", never "speech" or "music": peaks cannot tell them apart, and they are relative, so it describes the shape, never how loud the recording is.

Who narrates

The person's own screen reader, in their voice and at their speed: the text goes in the wave's aria-describedby, next to any ids your page put there. Nothing is ever spoken on its own.

For people without a screen reader, speech: true lets a click read it with the browser's own voice (speechSynthesis), with nothing to download. Only voices on the device are used, because some browsers' online voices send the text to a server; speech: { voices: 'any' } allows them.

Options

Option Default What it does
lang 'en' 'pt', 'pt-BR'…, 'auto', or any tag with your own words.
words built in Your own phrases, templates with {duration}, {at}, {count}…
times 'words' 'clock' says positions as 0:12.
text from the peaks Your own description, written ahead.
minPause automatic The shortest pause, in seconds (3 % of the sound, from 0.75 to 5).
threshold 0.06 Below this share of the loudest peak counts as quiet.
describedBy true Put the text in the wave's aria-describedby.
target none An element of yours that shows the text too.
announceWhenReady false Say it once if it arrives while the wave has focus.
keys false D says it again, P / Shift + P step through the parts.
pauseInValue false Add "pause" or "silence" to the wave's value.
speech false Let speak() read it with the browser's voice; { voices, rate }.
onChange none Called with the new text.

Written ahead of time

outlineSound and describeSound are pure functions on sonicframe/analysis, so a server can write the description when a file is uploaded and pass it as text, ready at the first focus. 

import { describeSound, outlineSound } from 'sonicframe/analysis';

const text = describeSound(outlineSound(peaks, duration), { lang: 'en' });
