Timeline

A ruler with labels on round seconds and minutes, in a lane above or below the bars. Zoomed in, it marks the part in view, down to tenths of a second.

Adding it

import { timeline } from 'sonicframe';

frame.use(timeline({ placement: 'above', height: '1rem' }));

Options

Option Default What it does
placement 'below' 'above' or 'below' the bars.
height 14 The lane's height, at least 1; the wave gives up that room. A number counts in CSS pixels; a length is written with its unit ('1rem', '14px').
minSpacing 48 The least space between labels, in CSS pixels; at least 8.
format m:ss Your own label for a moment, (seconds) => string.
color var(--sonicframe-timeline, #8a94a6) The ruler's color.
minor true A short mark halfway between labels.

The ruler is plain text in a lane, hidden from screen readers: the wave's own value already says the time.
