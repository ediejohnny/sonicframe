Installation

One package, no dependencies, three entry points. Install it with your package manager, or load it straight from a CDN.

With a package manager

SonicFrame is published on npm as sonicframe. Use whichever manager your project already uses: 

npm install sonicframe
pnpm add sonicframe
yarn add sonicframe
bun add sonicframe

It brings nothing else along: the published package has no runtime dependencies and no install scripts. Types come in the package, so TypeScript needs nothing extra.

Three entry points

Import only what the page needs. An app that draws waves never loads the ready-made player, and a server that reads peaks never loads anything that touches the DOM.

Import What is in it Use it for
sonicframe The frame (SonicFrame), every plugin, the play button, the volume control, the peaks readers and the analysis functions. Building your own player, or drawing waves with your own controls.
sonicframe/player createPlayer, the themes and palettes, and the <sonic-player> tag. A complete player in one call or one tag.
sonicframe/analysis Pure functions: levels, silences, the wave in words, and the waveform file writer. Servers, workers and build scripts (Node, Deno, Bun). 
import { SonicFrame, loadPeaks } from 'sonicframe';
import { createPlayer } from 'sonicframe/player';
import { writeWaveform } from 'sonicframe/analysis';

From a CDN

No build step? Any npm CDN serves the package as plain modules. Pin the version you tested: 

<script type="module">
    import { createPlayer } from 'https://cdn.jsdelivr.net/npm/sonicframe@0.4.0/dist/player.js';

    createPlayer({
        container: document.querySelector('#player'),
        src: '/voice.mp3',
    });
</script>
Tip A strict Content-Security-Policy keeps working: add the CDN to script-src, and nothing else is needed. SonicFrame sets no inline styles, runs no eval and starts no blob workers.

Module format

SonicFrame is shipped as standard ES modules ("type": "module"), compiled for ES2022. Every current bundler (Vite, webpack, Rollup, esbuild, Parcel) and every current browser loads it as is. There is no CommonJS build; in Node, use import (or a dynamic import() from CommonJS).

The package is marked free of side effects, so a bundler drops every plugin and function you do not import.
