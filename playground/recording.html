Recording

Record from the microphone with a live wave, hear the recording on a player, then send it to your app. The microphone is asked for only when someone presses record.

Try it

Press record and allow the microphone. Send keeps everything on this page and only says what it would hand over.

Adding it

import { createRecorder } from 'sonicframe/record';

createRecorder({
    container: document.querySelector('#recorder'),
    async onSend(recording) {
        const body = new FormData();
        body.append('audio', recording.blob);
        body.append('peaks', JSON.stringify(recording.peaks));
        const response = await fetch('/notes', { method: 'POST', body });

        if (!response.ok) {
            throw new Error('The note was not saved');
        }
    },
});

While onSend runs, the screen says it is sending. A rejection keeps the recording and says it could not be sent, so it can be sent again.

What the recording holds

Field What it is
blob The sound.
type Its audio type: Opus in WebM in Chrome, Edge and Firefox, MP4 in Safari.
duration Seconds recorded, pauses left out. A recorder's file often gives no length of its own, so keep this one.
peaks 1000 peaks from 0 to 1, decoded from the sound, ready for a player.
size In bytes.

The stages and their parts

Stage Parts by default
idle ['record']
recording ['discard', 'time', 'wave', 'pause', 'stop']
review ['discard', 'player', 'send']

parts sets any stage's list, from record, stop, pause, discard, send, time, wave, player and spacer. What went wrong, or what is under way, shows on a line under the parts. 

createRecorder({
    container,
    theme: 'bubble',
    live: 'fit',
    parts: {
        recording: ['wave', 'time', 'stop'],
        review: ['player', 'spacer', 'discard', 'send'],
    },
    onSend,
});

For screen readers

  • Every button has a name, and the focus moves to the main button of each stage: stop, then send.
  • The live region says "Recording", "Recording paused", "Recording stopped, 0:42", "Time limit reached" and why the microphone cannot be used.
  • The live wave is hidden from screen readers; the time is text.
  • a11y.announceEvery: 30 also says the time every 30 seconds while recording. Off by default.
  • a11y.lang and a11y.labels pick the language and your own words, as for the player.

Without a screen

import { Recorder, RecordError } from 'sonicframe/record';

const recorder = new Recorder({ maxSeconds: 60 });
recorder.on('level', (level, seconds) => meter.update(level));

try {
    await recorder.start(); // from a press
} catch (error) {
    if (error instanceof RecordError) {
        show(error.reason); // 'denied', 'missing', 'insecure', 'unsupported' or 'failed'
    }
}

const recording = await recorder.stop();

pause(), resume() and cancel() do what they say; levels holds the live levels, 20 a second. The recording stops on its own at its limit (a limit event, then stop).

On the tag

<sonic-recorder max="120" theme="bubble"></sonic-recorder>

<script type="module">
    import { defineSonicRecorder } from 'sonicframe/record';

    defineSonicRecorder();
    document.querySelector('sonic-recorder').addEventListener('sonicframe:send', (event) => {
        const [recording] = event.detail;
        upload(recording);
    });
</script>

Attribute Takes
max Seconds before it stops on its own.
live fit, or it scrolls.
window Seconds the scrolling wave shows.
theme, palette As on the player.
hold Present: record while held.
keep Present: keep the recording after Send.
idle-parts, recording-parts, review-parts Part names, separated by spaces.
a11y-lang, a11y-announce-every The language, and the seconds between two times said.

The events reach the element as sonicframe:state, sonicframe:recorded, sonicframe:send, sonicframe:sent and sonicframe:error. On the tag, Send counts as sent; for an upload that can fail, use createRecorder and its onSend. Changing an attribute starts over.

Options

Option Default What it does
maxSeconds 300 Seconds before it stops on its own, from 1 to 3600.
constraints echo, noise and gain control on The microphone's settings.
mimeType WebM Opus, MP4, Ogg Opus The audio types to try, in order; the first the browser can record wins.
audioBitsPerSecond the browser's The bitrate.
decode true Decode the sound for its peaks; off, or when decoding fails, the live levels.
peaks 1000 How many decoded peaks.
rate 20 Live levels a second, from 1 to 100.
maxBytes 100 MiB The largest recording; only lowers the default.
parts see above The parts of each stage.
live 'scroll' The live wave scrolls, or fits the whole recording ('fit').
window 10 Seconds the scrolling wave shows, from 2 to 60.
theme, look, palette, wave, bar, font the player's Dress the screen and the player of the recording.
onSend Gets the recording when Send is pressed.
afterSend 'reset' Start over, or keep the recording ('keep').
hold false Record while the button is held; a click still records.
a11y lang, labels and announceEvery.

Where it can record

  • Only on HTTPS pages (and localhost); elsewhere the screen says so.
  • In an iframe, only with allow="microphone".
  • The player of the recording plays a blob: address: a strict Content-Security-Policy needs media-src blob:.
  • Nothing leaves the page unless your onSend sends it.
