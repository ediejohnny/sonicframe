Upgrade guide

From 0.5 to 0.6. The public API only grew, and every new feature is off until you turn it on, so an upgrade changes almost nothing on its own; the things that do are listed first.

Update the package

npm install sonicframe@0.6

What can sound or look different

One second is said in the singular

A skip of one second now says "Back 1 second", not "Back 1 seconds", by each language's own plural rules. If you gave the player your own back and forward labels, they still serve both; add backOne and forwardOne for the singular.

A player in Portuguese speaks Portuguese everywhere

The volume slider's "muted", what the regions say and the markers' "and 3 more" spoke English whatever the player's language. They now speak it too. English stays the default.

Options that are not numbers fall back to the default

A number option given as NaN or as text now takes its default instead of breaking the part (no markers at all, a muted volume on an arrow key, a black spectrogram). If a page relied on one of those by accident, it now gets the default.

The package is larger, the recorder is apart

The new features make sonicframe/player larger. Recording lives in its own entry, sonicframe/record, so a page that does not record never loads it.

What you can turn on

New Where to read about it
Portuguese of Portugal (pt-PT), Spanish (es) and French (fr); a11y.lang on the frame and the controls; registerLanguage for a language of your own Languages
A player's own background (look.background), its motion (look.backgroundAnimation) and the tag's background- attributes Backgrounds
The lock screen and the media keys (mediaSession(), the player's mediaSession option and the tag's media- attributes) Lock screen and media keys
Recording from the microphone: createRecorder, Recorder, uploadRecording and the <sonic-recorder> tag Recording
a11y.tooltip.readable: the tooltip's text in black or white, whichever reads on its color Markers, Chapters

The record button of the recorder is red unless you pick another recordStyle. The recorder is new, so no page changes because of it.

For plugin authors

Nothing changes for a plugin written for 0.5. host.lang says the language the frame speaks, so a plugin can speak it too.

Fixed

  • A player no longer sets off "ResizeObserver loop completed with undelivered notifications", which error trackers and some test runners count as an error.
  • A player with a timeline above the wave and zoom no longer lays itself out again on every frame.
  • The regions' labels come back after the player builds its wave anew.
  • The shared tooltip keeps clear of the page's scrollbars.

Every change is in the changelog.
