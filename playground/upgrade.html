Upgrade guide

From 0.3 to 0.4. Every new feature is off until you turn it on, so an upgrade changes almost nothing on its own; the two things that do are listed first.

Update the package

npm install sonicframe@0.4

What can look different

Narrow players become voice notes

A ready-made player narrower than 22 rem (about 352 pixels), with the wave in its line, now keeps only the play button and the wave on that line; the time goes under the wave on the left and the other controls on the right. Wider players look exactly as before.

To keep the old single line at every width:

createPlayer({ container, src, look: { narrow: 0 } });

Or arrange the voice note your own way with narrowLine and narrowStart; see Parts and layouts.

The tag reads larger peaks files

<sonic-player peaks="…"> now reads its file with loadWaveform: up to 8 MB, and a file with more than 20,000 values is folded instead of refused. It also reads audiowaveform .dat files and takes their duration.

For plugin authors

With zoom on, the canvas shows a part of the sound. A plugin written for 0.3 keeps working while zoom is off; to follow the view, place things with paint.xAt(ratio), read presses from point.ratio and point.time, and listen to host.on('viewchange', …). See Writing a plugin.

Fixed

  • A sound longer than the decoder's ceiling is read evenly through, and the sample rate given back matches the samples.
  • exportClip with start and end draws only that range.
  • The plugins' shared overlay sits over the bars, never over a timeline lane.
  • On a phone, zoom buttons no longer crush the wave.
