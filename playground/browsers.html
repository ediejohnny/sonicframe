Browser support

Current Chrome, Edge, Firefox and Safari, on desktops and phones. Where a browser lacks a feature, SonicFrame falls back on its own; nothing needs a polyfill.

What it needs

  • ES2022 modules (every current browser).
  • A 2D canvas, ResizeObserver and IntersectionObserver.
  • Pointer events, for the mouse, pen and touch alike.

Fallbacks

Where the browser lacks SonicFrame
roundRect on the canvas draws rounded bars with arcs.
sizes in device pixels (device-pixel-content-box) multiplies CSS pixels by the screen density, and redraws when the window moves to another screen.
IntersectionObserver treats every frame as on screen (no lazy loading).
a settable volume (iOS) shows only the mute button of the volume control.
a local voice for speechSynthesis says so through the live region; the screen reader still reads the description.

Optional features

  • Live frequency and clip export need Web Audio; clips also need MediaRecorder. Without them, these plugins report an error and the rest keeps working.
  • Reduced motion is read from prefers-reduced-motion: no grow-in, no animated buttons, and the zoom's centered follow turns a page at a time.

Servers and workers

sonicframe/analysis touches no DOM, so it runs in Node 18 and newer, Deno, Bun and web workers.
