Analysis and clips

Pure functions that measure a sound, safe in Node or a worker, and a recorder that turns a stretch of the wave into a short video to share.

Analysis

On sonicframe/analysis (and the main entry). None of them touch the DOM.

Function What it gives
levels(samples, sampleRate, …) Loudness over time.
peakLevel(samples) The loudest sample, as { peak, peakDb }.
findSilences(samples, sampleRate, options) Quiet stretches, from samples.
silencesFromPeaks(peaks, duration, options) Quiet stretches, from peaks.
mixdown(source, max) One channel from many, at most max samples.
outlineSound, describeSound The wave in words, ahead of time.
writeWaveform An audiowaveform file; see Ready-made peaks.

Exporting a clip

frame.exportClip(options) records a short video of the wave playing, in the frame's drawing and colors, with the sound. It resolves with { blob, mimeType, duration }. 

button.addEventListener('click', async () => {
    const clip = await frame.exportClip({ start: 8, end: 16, caption: 'The second verse' });
    download(clip.blob, `verse.${clip.mimeType.includes('mp4') ? 'mp4' : 'webm'}`);
});
Option What it does
start, end The stretch, in seconds.
caption A line of text in the video.
width, height, fps The video's size and frame rate (capped).
signal An AbortSignal that cancels it, download included.
maxSourceSeconds The longest source decoded (600 by default).
Call it from a click Browsers keep audio suspended until the person does something. A clip whose audio never starts is rejected instead of waiting forever.

The source is decoded whole before the clip is cut, about 23 MB of memory per minute of stereo audio, so it is limited to maxSourceSeconds. Raise it where memory allows (Infinity lifts it), or pass a Blob or AudioBuffer holding just the part to clip.
